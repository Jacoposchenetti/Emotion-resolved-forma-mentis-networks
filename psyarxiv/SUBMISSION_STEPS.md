# How to post the preprint on PsyArXiv (step by step)

This folder is the ready-to-submit package.

**Contents**
- `preprint.pdf` — the manuscript (line-numbered, CC-BY-ready, with the "Submitted to
  Meta-Psychology" statement on page 1).
- `preprint_metadata.md` — every field to paste into the submission form.

**Before you start (one-time)**
1. Create a free account at https://osf.io (PsyArXiv runs on OSF).
2. Create an ORCID iD at https://orcid.org and add it to `preprint_metadata.md`.

**Submit**
1. Go to https://osf.io/preprints/psyarxiv and click **Add a preprint**.
2. Choose/confirm **PsyArXiv** as the provider.
3. **Upload** `preprint.pdf`.
4. Paste **Title**, **Abstract**, **Keywords/Tags** from `preprint_metadata.md`.
5. Set **License** = **CC-BY 4.0**.
6. Add **Author** (yourself) with affiliation and ORCID; add email.
7. Select **Disciplines**: Quantitative Psychology (primary), Cognitive Psychology.
8. Under **Supplements / links**, add the GitHub repository and the OSF data link.
9. Preregistration: **None**. Conflict of interest / Funding: **None**.
10. Submit. PsyArXiv assigns a **DOI** within minutes.

**After you have the DOI**
- Put the preprint DOI on page 1 of the manuscript (Meta-Psychology requires the preprint to
  have a DOI), then submit to Meta-Psychology at
  https://open.lnu.se/index.php/metapsychology following their author guidelines.
- Optional but recommended for Meta-Psychology's transparency requirements: create an **OSF
  project** that mirrors the GitHub repo (data, code, README, a data dictionary/codebook) and
  link it from the manuscript, since MP asks specifically for an OSF component.

**Notes**
- Two references (Ciringione 2025; Franchino 2026) are themselves arXiv preprints; if either is
  published before you submit to MP, update to the version of record.
- Nothing here charges a fee: PsyArXiv is free, and Meta-Psychology is diamond open access.
